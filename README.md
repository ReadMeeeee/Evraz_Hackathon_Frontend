# Evraz_Hackathon_Frontend

Frontend (UI + lightweight proxy) для хакатонного RAG-обработчика на бэкенде.

Проект поднимает небольшой сервер на **Node.js + Express**, который:
1) отдаёт веб-страницу с Drag&Drop загрузкой файлов,  
2) принимает файл через `/send` (multer),  
3) валидирует расширение и (для `.zip`) определяет тип вложенного кода,  
4) отправляет файл в бэкенд по HTTP (axios + multipart/form-data),  
5) сохраняет ответ как `corrections.pdf` и отдаёт пользователю скачивание.

---

## Что это, зачем и куда

Цель проекта - дать простой интерфейс для загрузки исходников/архивов в RAG-сервис:
- `.py`, `.cs`, `.ts`
- `.zip` (внутри должен быть хотя бы один файл из перечисленных расширений)

Бэкенд возвращает результат в виде PDF (например, отчёт/проверка/правки), который пользователь скачивает.

---

## Поддерживаемые форматы

- Прямые файлы: **.py / .cs / .ts**
- Архив: **.zip**
  - внутри архива должен быть хотя бы один файл `.py/.cs/.ts`
  - тип определяется по первому найденному файлу (не директория)

!(Иначе backend просто не примет другие типы)!

---

## Как это работает (pipeline)

1. Пользователь открывает страницу `/` (статические файлы из `public/`)
2. Загружает файл и отправляет форму
3. `POST /send`:
   - проверяет расширение
   - переименовывает файл в `uploads/<uuid>.<ext>`
   - для `.zip` определяет язык по содержимому архива
   - проксирует файл в бэкенд:
     - `.zip` → `POST <BACKEND_BASE_URL>/zip`
     - `.py/.cs/.ts` → `POST <BACKEND_BASE_URL>/file`
     - передаёт заголовок `type: py|cs|ts`
4. Ответ от бэка (stream) пишется в `corrections.pdf`
5. Пользователь скачивает PDF

## Структура проекта

- `public/`
  - `index.html` - UI страницы загрузки (Drag&Drop + выбор файла)
  - `images/` - фоновые картинки
- `app.js` - Express сервер + маршрут `/send`
- `requestHandler.j
- `axiosClient.js` — клиент для отправки файла в бэкенд
- `fileUtils.js` — валидация расширений, rename, анализ `.zip`
- `Dockerfile` — контейнеризация

## Установка и запуск

### Локально

```bash
npm install
node app.js
```

### Docker

```bash
docker build -t evraz-hackathon-frontend .
docker run --rm -p 8080:8080 evraz-hackathon-frontend
```

По умолчанию сервер стартует на: http://localhost:8080
